# PMC7 反射板シミュレーター

第7回 電波伝搬モデリングコンペティション（PMC7）の評価部屋で、反射板の配置と送信ビームの向きを変えたときに、24か所の受信点の受信電力と評価指標がどう変わるかを試すための簡易シミュレーターです。メンバーで配置のアイデアを出し合うための道具で、良さそうな案は Wireless InSite で詳しく確認する前提です。

ブラウザで `index.html` を開くだけで動きます（インストール不要）。

## できること

- 反射板（60 × 40 cm、最大6枚）を、設置できる壁に沿ってドラッグまたは座標入力で動かす。壁からの傾きも変えられる
- 送信ビームの方位角を変える。「最良の向きを探す」で総当たり探索
- 評価指標 ΔP_avg、ΔP_low、A_total をその場で計算
- 受信点をクリックすると、その点に届く主な経路を表示
- 部屋全体の受信電力をヒートマップ表示
- 配置に名前を付けて保存し、指標を表で比較（保存はそのブラウザ内だけ）
- 配置をリンクにして共有（URL の `#` 以降に配置が入る）

## 座標

原点は D壁と C壁の角。x は B壁方向、y は A壁方向（単位 m）。送信機は (6.04, 2.00)、アンテナ高はすべて 1.6 m。

## モデル

- 平面（高さ 1.6 m）だけを扱う 2D の鏡像法。反射は既定で4回まで
- 金属棚の端はナイフエッジ回折（ITU-R P.526 の近似式）で扱う
- 石膏壁は TE 偏波のフレネル反射（比誘電率 2.73）に、実測に合わせた補正（既定 +6 dB）を足す。金属は全反射
- 送信アンテナの水平パターンは配布データ（tx_antenna_pattern.xlsx）を使用。受信はオムニ 3 dBi
- 電力は位相を無視して足し合わせる（20 MHz の周波数平均の代わり）
- 基準環境の値は配布資料の実測値をそのまま使い、対処後は「実測値 ＋ モデルが計算した変化量」で表示する

## 限界

- 天井・床の反射、板の有限サイズによる広がり、散乱は入っていない
- 基準環境の実測24点との差は、一律のずれを補正したあとで標準偏差 3〜4 dB 程度。数 dB の差で案の順位を決めないこと
- 「壁の反射の強さ」の設定で結果が大きく変わる。0 と +6 dB の両方で効く案を選ぶのがおすすめ

## 出典

部屋の寸法、受信点の位置、基準環境の実測値、送信アンテナのパターンは PMC7 の配布資料による。
